# Aria

An Open Multimodal Native Mixture-of-Experts Model.

## Overview

Aria is an open multimodal native mixture-of-experts (moE) model that can handle various modalities including text, images, and videos. It is designed to be efficient and scalable while maintaining high performance across different tasks.

## Key Features

- **Multimodal Native**: Designed from the ground up to handle multiple modalities seamlessly
- **Mixture-of-Experts**: Utilizes MoE architecture for efficient scaling and performance
- **Open Source**: Fully open source with weights and code available
